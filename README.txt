PolyAletheia LAMMPS Simulation Package
--------------------------------------
Molecule: CC(c1ccccc1)
Temperature: 298 K
Pressure: 1 atm

Instructions:
1. Extract this ZIP file.
2. Run command: lmp -in in.lammps
   (Or 'wsl lmp -in in.lammps' on Windows)
3. Upload 'log.lammps' back to the Web App to verify.
